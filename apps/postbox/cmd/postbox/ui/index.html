AN ADDRESS, NOT AN HTTP URL

Postbox will write to an application.

Entering a mailweb:// address does not make an HTTP request to a web server. Postbox wraps the address in a MailWeb request, privately emails it to an application that speaks MailWeb, waits for the application’s reply, and renders the semantic document enclosed in that private message.

SPECULATIVE PRIVATE CORRESPONDENCE

prEmail writes ahead.

When a response email contains eligible same-origin GET links, Postbox may privately write to as many as three of those MailWeb destinations before you click them. Their emailed replies are filed in memory for 60 seconds, making later browsing feel instant.

It never pre-mails forms, POST requests, buttons, external addresses, or links found inside a prefetched reply. The activity remains visible because speculative correspondence can reveal interest in pages you never actually visit.
